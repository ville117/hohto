# Hohto
a 3D renderer made in [Rust](https://rust-lang.org/) & for fun!
> If the program doesn't work or you encounter any other problems, please report it here [Issues](https://github.com/ville117/hohto/issues)

## Requirments
+ [Rust](https://rust-lang.org/)
GPU with [Vulkan](https://www.vulkan.org/) drivers that support
+ Vulkan 1.3
+ Buffer device address
+ Dynamic rendering
+ [`VK_EXT_shader_object`](https://docs.vulkan.org/refpages/latest/refpages/source/VK_EXT_shader_object.html)
+ [`slangc`](https://github.com/shader-slang/slang) available on `PATH`
+ [Git](https://git-scm.com/)
+ [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)

## Building
```
git clone https://github.com/ville117/hohto.git
cd hohto
cargo build --release
```
