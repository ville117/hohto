a 3D renderer made in [Rust](https://rust-lang.org/) & for fun!

## Requirements <img src="https://external-content.duckduckgo.com/iu/?u=https%3A%2F%2Fblog.mbedded.ninja%2F_astro%2Frust-programming-language-logo-white-background.Ndag0t3d.png&f=1&nofb=1&ipt=4bb77320a17c3f36e96e0f06123cb7e746fe621b89c91fed955d6b35c47ff80f&ipo=images" width="16" height="16" alt="Rust-logo"> <img src="https://external-content.duckduckgo.com/iu/?u=https%3A%2F%2Fimages.seeklogo.com%2Flogo-png%2F41%2F2%2Fvulkan-logo-png_seeklogo-411988.png&f=1&nofb=1&ipt=32cb6a33e49bece0985de58186f056474abba80805321ea41fd9dc1f6acfe034&ipo=images" width="16" height="16" alt="Vulkan-logo"> <img src="https://external-content.duckduckgo.com/iu/?u=https%3A%2F%2Flogospng.org%2Fdownload%2Fgit%2Fgit-2048.png&f=1&nofb=1&ipt=92621cf0ee52ec2bfb7d1b34fa6ddc3c44e07298346715b2e73b824398c03bd2&ipo=images" width="16" height="16" alt="git-logo">
+ [Rust](https://rust-lang.org/)
+ [Git](https://git-scm.com/)
+ [Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)
+ a [GPU](https://en.wikipedia.org/wiki/Graphics_processing_unit) with [Vulkan](https://www.vulkan.org/) drivers that support
  + Vulkan 1.3
  + Buffer device address
  + Dynamic rendering
  + [`VK_EXT_shader_object`](https://docs.vulkan.org/refpages/latest/refpages/source/VK_EXT_shader_object.html)
  + [`slangc`](https://github.com/shader-slang/slang) available on `PATH`

## Building
```
git clone https://github.com/ville117/hohto.git
cd hohto
cargo build --release
```
> If the program doesn't work or you encounter any other problems, please report it here: [Issues](https://github.com/ville117/hohto/issues)
